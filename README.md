## Mô Tả Dự Án
Website tĩnh giới thiệu sản phẩm công nghệ TechStore được xây dựng bằng HTML5 và CSS3.

## Cấu Trúc Website
- `index.html`: Trang chủ giới thiệu chung.
- `about.html`: Trang giới thiệu tầm nhìn và giá trị cốt lõi.
- `products.html`: Trang danh mục sản phẩm.
- `contact.html`: Trang biểu mẫu liên hệ.
- `css/style.css`: File định dạng giao diện chung và responsive.

## Công Nghệ Sử Dụng
- HTML5 (Semantic HTML)
- CSS3 (Flexbox, Grid, Media Queries)
- GitHub Pages (Triển khai website)
